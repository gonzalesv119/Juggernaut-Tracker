JUGGERNAUT HOME SCREEN APP — IPHONE SETUP

This folder is a PWA-ready version of your Juggernaut tracker.

WHAT YOU GET
- iPhone-friendly layout (tuned for iPhone 14 Plus)
- Home Screen icon
- Standalone/full-screen app mode
- Offline caching after the first hosted visit
- Same local saving, training maxes, reps, AMRAP PRs, accessories, and notes

IMPORTANT
For a permanent Home Screen web app, these files need to be hosted together on a normal HTTPS webpage. Keep the folder structure exactly as-is.

AFTER IT IS HOSTED
1. Open the tracker URL in Safari on your iPhone.
2. Tap Safari's Share button.
3. Tap "Add to Home Screen".
4. Name it "Juggernaut" (or anything you want), then tap Add.
5. Launch it from the new JM icon on your Home Screen.

MOVING YOUR EXISTING TRACKER DATA
Your current browser data will not automatically move to a different website address.
In the old tracker: Settings / Backup > Export backup.
In the new Home Screen app: Settings / Backup > Import backup.
